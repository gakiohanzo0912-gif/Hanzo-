# 姪っ子と豆柴の冒険

姪っ子と、実家の豆柴(黒柴)が主人公のドラクエ風ドット絵RPG。ブラウザで遊べます。

いまは **第1章のおつかいが最後まで遊べる**ところまで。第2章は coming soon。

公開ページ: https://gakiohanzo0912-gif.github.io/Hanzo-/

(更新したら、index.html の `?v=` の数字を上げると、ブラウザの古いキャッシュを避けられます)

## いまできること(第1章のおつかい)

0. タイトル画面のあと、黒い画面で「2026年9月15日 はれ」のはじまりのおはなし。2階の自分の部屋からスタート(階段で1階へ)
1. 1階でママ(ごはん作り中)に話しかける → 「お店でチョコを買ってきて」と頼まれて、500円をもらう
2. パパに話しかける → 「道中は危ないから、湖で釣りをしているおじさんにビールを渡して仲間にしなさい」と、ビールをもらう
3. 湖のおじさんにビールを渡す → **おじさんが仲間になって、豆柴のうしろからついてくる**
4. お店のカウンターでチョコを買う(120円)
5. ママにチョコを渡すと、第1章クリア(第2章は coming soon)

家・お店には、ドアに歩いて入れます(入口のマットから出られます)。

## せんとう

- **くさむら**(外の草・花のところ)を歩くと、ときどき **てきが出てきます**(ママにおつかいを頼まれたあとから)。コウモリ・ちびコウモリ・まっくろ・どくびんが、1〜3体で出ます。
- **お店でチョコを買う**と、店員さんの正体の **魔女・静代** とボス戦になります。勝つとチョコレートをタダでもらえます(負けても、げんきが回復して、またちょうせんできます)。
- コマンドは「たたかう」「とくぎ」「ぼうぎょ」「にげる」(ボス戦はにげられません)。
  - 姪っ子の とくぎ = **いたいの とんでけ**(いちばん弱ったなかまを回復) / 豆柴 = **ワンワン ほえる**(てきをおびえさせる) / おじさん = **よっぱらいパンチ**(強いけど、ときどき外れる)
  - なかまが多いほど有利です(おじさんを仲間にしておくと、ボスがぐっと楽になります)。
- HPとMPは戦闘のあとも続きます。ふつうのてきに勝つと少し回復して、**おうちに入ると全回復**。みんなやられたら、おうちで目が覚めます。

## 動かしかた

`index.html` をブラウザで開くだけで動きます。うまく動かないときは、このフォルダで次を実行して `http://localhost:8000` を開きます。

```
python3 -m http.server 8000
```

ネットで公開したいときは、GitHub の Settings → Pages で、Branch を `main`・フォルダを `/ (root)` にします。

## マップを変える

`src/scenes.js` の `rows` を書き換えます。外は
`T=木 .=草 ,=花 ==道 ~=水 B=橋 F=柵 R=岩 H=家 D=家の入り口 S=お店 E=お店の入り口`、
家の中・お店の中は
`W=かべ f=ゆか r=ラグ M=出入り口 T=テーブル S=本だな K=台所 P=植木 C/B=カウンター G=商品だな`。
`warps` でドアの行き先、`npcs` で人の位置を決めます。

## キャラ画像を作りなおす

`assets/source/` の画像を差し替えて(姪っ子・犬は4行×3列、おじさんは5行×3列(下・右・左・上・釣り)、パパは4行×4列、ママは4行×5列(下・左・右・上))、

```
pip install numpy pillow scipy
python3 tools/build_sprites.py
```

を実行すると `assets/sprites/` が作りなおされます。キャラごとの大きさは `tools/build_sprites.py` の `SCALE` でそろえています。
