# 姪っ子と豆柴の冒険

姪っ子と、実家の豆柴(黒柴)が主人公のドラクエ風ドット絵RPG。ブラウザで遊べます。

いまは **第1章の仮マップを歩き回れるところまで**。第2章は coming soon。

## いまできること

- 姪っ子を操作して、仮マップ(家・道・池と橋・森)を歩く
- 豆柴が、姪っ子の通ったあとを **後ろからついてくる**
- 木・水・柵・岩・家には入れない(橋はわたれる)

## 遊びかた

| 操作 | |
| --- | --- |
| 矢印キー / WASD | 移動(押しつづけると歩きつづける) |
| 画面のボタン ▲◀▼▶ | スマホ・タブレットでの移動 |
| G | マス目と座標の表示(マップづくり用) |

## 動かしかた

`index.html` をブラウザで開くだけで動きます。うまく動かないときは、このフォルダで次を実行して `http://localhost:8000` を開きます。

```
python3 -m http.server 8000
```

ネットで公開したいときは、GitHub の Settings → Pages で、Branch を `main`・フォルダを `/ (root)` にします。

## フォルダ

```
index.html, style.css      画面
src/map.js                 マップ(1文字が1マス。手で書き換えられます)
src/world.js               歩く・犬がついてくる動き(絵に関係しない部分)
src/art.js                 仮マップの絵(プログラムで描いています)
src/main.js                表示・キーやタッチの操作・ゲームループ
assets/source/             もとになったキャラシート(Geminiで作ったもの)
assets/sprites/            ゲームで使うキャラ画像(自動で作られます)
tools/build_sprites.py     キャラシート → ゲーム用画像
tools/test-world.js        動きのテスト
```

## マップを変える

`src/map.js` の `rows` を書き換えます。

```
T=木  .=草  ,=花  ==道  ~=水  B=橋  F=柵  R=岩  H=家  D=家の入り口
```

姪っ子のスタート位置は `spawn`。犬は、向きの反対側からスタートします。

## キャラ画像を作りなおす

`assets/source/niece-sheet.jpg` と `dog-sheet.jpg`(4行×3列のシート)を差し替えて、

```
pip install numpy pillow scipy
python3 tools/build_sprites.py
```

背景の緑を透明にして、元のドット解像度に戻し、`assets/sprites/` にゲーム用の画像を作ります。

- 姪っ子 … 下・左・右・上の4方向、歩き2コマ+立ち
- 豆柴 … 下・右・上は元の絵、左は右を反転
- 上向きは1コマしかないため、左右反転を交互に出して歩きにしています。足の動きを付けたいときは、上向きの歩きコマを足してください。
